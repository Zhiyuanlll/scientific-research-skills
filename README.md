# scientific-research-skills · 科研全流程技能工具集

这套工具集包含 23 个技能，支持从理解研究背景、文献推荐与精读、知识沉淀、研究问题与证据计划，到工作流搭建、独立队列执行、统计绘图、论文写作、投稿返修和科研回顾的完整流程。

知识库将文献与研究认识沉淀为可复用的理论、方法和方向证据；工作流技能定义阶段与科学验收，计算队列技能把正式科研计算交给独立服务或计算调度器，避免依赖聊天持续活跃；周回顾与计划贯穿各研究阶段，核对真实进展、维护研究状态并衔接后续工作。每项技能可以独立按需使用，也可通过来源记录和交付物协作。

1. [整体科研流程](docs/00_整体科研流程.md)：主线、周期反馈、交接产物及完整研究示例。
2. [安装与首次使用](docs/01_安装与首次使用.md)：完整或按需安装、更新、验证与调用。
3. [技能功能与使用示例](docs/02_各技能功能与示例.md)：按科研流程介绍 23 项能力及操作示例。
4. [研究状态与周期协同](docs/03_研究状态与周期协同.md)：推荐配置、知识维护、周回顾与计划、资料交接和日程安排。
5. [依赖与常见问题](docs/04_依赖与常见问题.md)：检索、下载、独立计算服务、绘图、知识库审计、周报公式和 HTML 等依赖。
6. [打包与验证记录](docs/05_打包与验证记录.md)：文件快照、分享版适配和实际检查范围。

也可用浏览器离线打开 [完整使用说明.html](完整使用说明.html)。

从 GitHub 获取后，在仓库根目录运行：

```bash
git clone https://github.com/Zhiyuanlll/scientific-research-skills.git
cd scientific-research-skills
python3 verify_package.py
python3 install_skills.py --dry-run
python3 install_skills.py
```

默认目标为 `~/.agents/skills/`，可用 `--target` 指定实际技能目录，`--only` 按需选择并带上包内依赖。不同内容的同名技能不会被覆盖。Windows 可按本机 Python 安装将 `python3` 换成 `py -3`。

正式科研计算无论长短，都应通过独立后端执行，包含单个小算例、参数扫描和批量任务。用户授权“开始计算”后，Codex 准备计划、核查资源并实际执行提交，再报告服务标识、日志、心跳与恢复条件；无需用户另行手动提交。技能可按任务自动选用，也可显式请求：“使用 $computation-queue-runner，开始这些正式计算，关闭 Codex 后队列仍继续。”语法检查、单元测试和短暂环境检查属于开发检查，按其用途执行。

随附执行器面向 Linux 和 systemd 用户服务；集群上优先对接已有 Slurm 等调度器。安装技能本身不会提交任务，关闭 Codex 后继续也不等于保证主机休眠、重启或断电期间仍在计算。

安装技能不等于安装外部工具、接入数据库或建立定时任务。所有技能目录应完整保留；研究数据、知识库、周报、推荐记录、访问权限和计算资源由使用者自行配置。包内不含个人聊天、密钥、机构账号、私人科研结果或 HEA 求解器。

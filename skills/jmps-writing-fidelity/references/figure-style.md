# 论文图件风格、格式与字体

仅在任务涉及图件视觉样式、排版或导出时读取。此参考包含通用原则和一个从既有论文图件提取的可选个人模板，二者不能混为期刊统一规定。语言润色不自动调用绘图、修改图中数据或更改论文插图。

## 选择适用的风格

- 先采用用户当前明确要求、所提供样图和项目约定，再按目标期刊的具体要求调整。未指定个人风格时使用下述通用原则，不自动采用 Times New Roman、橙蓝配色或固定尺寸。
- 需要核实投稿的字体、尺寸或分辨率限制时查阅目标期刊官方指南，不凭某篇已发表论文推断全刊要求。只做样式记录或个人模板复用时，无需为此检索期刊规定。
- 修改已有图时先读生成代码、当前样图和实际文件；区分代码初始默认值、后续覆盖值以及最终导出结果。代码声明某种字体不等于该字体实际用于 PDF；检查字体嵌入或渲染结果，记录缺失字体及实际替代。
- 使用当前项目已有的绘图语言和工具；本参考不要求 Python 或 R，也不要求安装其他技能。没有生成代码时，只记录能够从图件可靠确认的设置；不得将目测字号作为准确参数。

## 通用图表原则

| 项目 | 处理原则 |
| --- | --- |
| 字体与数学符号 | 同篇论文保持清楚、协调的字体体系。变量、单位、函数名和向量的字形服从学科语义及稿件定义，不能为统一外观取消有意义的粗体、斜体或上下标区别。 |
| 字号 | 以插入论文后的实际大小判断可读性，并区分轴标题、刻度、图例、面板编号和注释。不能把绘图画布上的字号直接当作最终印刷字号。 |
| 线条与符号 | 同类数据和模型使用一致的线宽、标记、线型和含义。缩小后仍须可辨；不得以线宽、透明度或遮挡掩盖局部偏离和异常数据。 |
| 配色 | 用颜色表达稳定的对象或条件对应关系，并结合标记、线型或标签区分对象。顺序量、发散量和类别量按其数据含义选色；不得改变色标范围或中点来夸大结果。 |
| 坐标与单位 | 标签、单位、归一化、对数轴和参考线含义明确。比较面板保持可解释的尺度；必要的截断或不同尺度应清楚说明。 |
| 面板布局 | 按科学比较关系安排顺序，对齐同类面板的绘图区、轴标题、图例和色条。面板编号样式统一，不遮挡数据，也不为填满空白而制造新内容。 |
| 空间图与场图 | 需要体现实际几何时保持真实的坐标比例。需要放大或变形显示时明确说明；等比例坐标不是所有趋势图的默认要求。 |
| 留白与背景 | 保留读取标签和区分面板所需的留白。优先减少无作用的空白；网格和背景色只在帮助读数或表达分组时使用。 |
| 导出 | 按目标期刊和用途选择矢量或栅格格式。矢量文件检查字体及嵌入的栅格内容；栅格文件按最终尺寸检查像素和分辨率。提高 dpi 不能修复低分辨率原图或矢量文字问题。 |

缩放时可用 `最终字号 = 源字号 × 插入宽度 / 源画布宽度` 估计统一缩放后的字号；宽度需使用相同单位。如果存在后续裁剪、拼图、非等比缩放或再次转换，应检查最终文件，而不能仅靠该估计。

样式修改必须保留原数据、采样点、统计定义、误差范围、拟合条件、坐标映射和图文含义。平滑、筛选、删点、改变基准或误差定义属于科学内容变化，不能当作美化静默执行。

## 可选个人模板：Times 衬线字体与橙蓝配色

这是既有论文的视觉模板，不是所有期刊或其他作者必须采用的规则。用户明确要求“沿用这篇论文的绘图风格”“采用此个人模板”或提供与之匹配的样图时使用；仅要求通用论文润色或通用绘图时不启用。

### 字体、配色与布局

- 主要英文文字优先 Times New Roman。当前正文图中还使用 Computer Modern 或 STIX 数学字体；公式字体按所复用图的实际设置保持协调，不强制所有数学字符来自 Times New Roman。
- 变量斜体、单位和说明文字正体；字重由原图和科学语义决定。较早的工作流采用加粗字体，但近期正文图主要使用常规字重，不能将旧版“全部粗体”视为当前整篇论文要求。
- 原项目中橙色对应一类贡献、蓝色对应另一类贡献，近黑色对应联合结果。典型色值为橙 `#ff8800`、蓝 `#488abe`、近黑 `#262626`；同一组图保留相同对应关系。
- 此配色复用于其他研究方向时，用户需要指定颜色对应的对象；不将原项目的 Solute、Fault、Full 名称或物理含义转移到新模型。用户有自己的配色时按其约定。
- 多面板保持整齐对齐，使用一致的 `(a)`、`(b)` 等编号。图例通常无外框，放在不遮挡数据的位置；重复面板可共享图例，但仍需能辨认各曲线。
- 趋势图通常不用常规网格，白色或很浅的分组背景即可。现有双列比较图使用浅暖色 `#fbf8f5` 和浅蓝色 `#f3f8fc`；背景是可选项，不用于改变数据视觉权重。

### 文件与导出

- 现有正文图优先保留矢量 PDF；需要可编辑中间文件时保留 SVG。核对文字、数学符号、线条和标记导出后的表现，避免字体替代、缺字和裁切。
- 现有代码中使用 `pdf.fonttype=42` 和 `svg.fonttype=none`；这是 Matplotlib 中的输出选择，不是其他工具必须模拟的参数，也不保证接收者拥有相同字体。
- 部分新图提供 `600 dpi` 的 PNG 或 TIFF，预览图及较早工作流使用 `300 dpi`。这些是现有导出设置，投稿时仍需按图像类型、最终尺寸和具体期刊要求确定。
- 风格分享包只包含规则，不附带论文图件、数据或字体文件。运行环境缺少指定字体时说明实际替代，并核对样图；不能在报告中将替代字体称为 Times New Roman。

## 使用与交付

对已有图只做用户授权的样式调整。保留数据和生成来源，在最终插入尺寸检查字体可读性、面板对齐、标注遮挡、边界裁切、误差可见性及颜色对应关系。没有执行绘图或导出验证时，不报告这些检查已经通过。

其他作者可直接替换本文件的个人模板，或在请求中给出自己的字体、字号、颜色、尺寸和输出格式；保真原则继续适用，不强制使用本模板。

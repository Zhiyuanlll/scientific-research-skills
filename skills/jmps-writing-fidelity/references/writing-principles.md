# 基础论文写作与原义保护原则

帮助作者清楚、自然、准确地表达已有研究内容。适用于不同学科、研究方法、稿件类型和目标期刊，不预设某个领域的术语、某种期刊风格或统一的文章结构。无需其他技能或特定软件即可提供文字建议；文件编辑、文献核验及编译按当前环境的能力执行。

## 确定任务和依据

- 区分起草、结构调整、语言润色、翻译和逐句审核。语言润色不自动扩大为重建论证、补充机制、增加文献或调整研究贡献；用户明确要求的结构调整可以重排已有内容，但不能改变其依据和结论。
- 以当前稿件、邻近上下文、定义、图表及作者提供的依据为准。按需读取相关部分；短段润色无需先检查全文。只在缺失信息会实质影响结果时询问，其余使用已有信息继续。
- 作者当前要求与已确认的项目术语优先；期刊格式和学科惯例用于选择表达形式，不得据此篡改研究内容或消除有意义的限定。没有目标期刊时采用中性的学术表达，不自行指定期刊风格。
- 使用作者提供的期刊指南、文章模板或指定范文时区分格式要求与可选风格。如果任务需要核实当前期刊规定，查阅官方指南；引用某期刊的论文并不意味着稿件投向该期刊。
- 起草时只使用已提供或已核实的研究依据。缺少的结果、数值、文献或机制应标为待补信息，不能为了段落完整而编造。语言润色本身不能确认研究方法或模型正确。

## 写作与论证

- 直接陈述研究问题、方法、结果、解释、必要定义和适用范围。正式稿中不保留作者与助手的提醒、假想读者纠偏、运行进度或写作安排；其中有科学意义的内容改写为定义、方法条件或证据范围。
- 让段落围绕可辨认的论证任务展开，交代相邻内容之间真正的关系。过渡应说明研究依据如何支持下一步问题或比较，避免用宽泛的背景句重复已经建立的内容。
- 以稿件类型和现有逻辑决定结构，不强制所有论文采用实验论文的章节顺序。摘要、引言、方法、结果、讨论等只在适用时承担相应功能；不凭空增加新颖性、普适性或应用价值。
- 区分已有研究的发现、本研究的结果、方法假设、理论预测及作者的解释。文献综述保留不同研究之间的分歧、条件和证据强弱，不能为了叙述顺畅改成一致结论。
- 数值应服务于描述、复现、比较或推论；保留必要的定量结果，不机械删除连续数值报告。只有现有证据支持且论证需要时补充结果的意义，不为每个图或段落强加机制解释或总结句。
- 减少没有科学内容的重复和防御性措辞，同时保留假设、数据筛选、例外、失败检验、未验证范围、研究局限及必要的数值处理。否定句和限定词具有科学意义时应保留。

## 语言表达

- 优先采用准确、常用且符合学科习惯的词语。修正语法、修饰关系、指代不清和不必要的名词堆叠；不要为了变化而替换已定义的术语，也不把简洁等同于删减信息。
- 已自然、准确的句子可以不改。只有当定义、条件、结果或修饰关系难以辨认时才拆句；不设统一句长上限，也不机械合并短句。
- 主动或被动语态、第一人称、时态和句式服从内容与目标期刊要求。区分当前定义、图表呈现的观察、已完成的方法以及既有研究；不一律删除第一人称或统一为某个时态。
- 图表、公式和章节引用放在自然的句子或分句边界，保持表达多样但对象明确。缩写、大小写和编号按实际模板处理，不统一强制使用某种图引用格式。
- 只有上下文足以确定指代时才用具体对象替换代词。若更流畅的表达会引入新的科学解释，保留原义并说明问题，而不代替作者补全解释。

## 保持原义：逐项核对

润色和翻译前后核对以下内容；不是要求每次都向作者输出这张检查表。

| 核对项 | 应保留的实质内容 |
| --- | --- |
| 对象与操作 | 研究对象、属性、构念、变量及其作用；测量、估计、拟合、推导、模拟、平均或积分的具体操作。 |
| 条件与范围 | 固定和改变的条件、控制变量、边界或初始条件、数据筛选、模型假设、近似阶次、参数范围及适用对象。 |
| 比较 | 比较对象和基准、增减方向、差的正负、相对量的分母、归一化方式和同一条件下的对应关系。 |
| 逻辑与证据 | 因果与相关、观察与预测、拟合与验证、存在与普遍性、必要与充分、量词和否定词的作用范围、时序，以及可能、支持、证明等不同强度。 |
| 统计与采样 | 样本单位和层级、独立性与配对、平均和极值的运算顺序、时间与空间统计、区间及误差所表示的不确定性。 |
| 数学与数值 | 公式关系、符号、正负号、上下标、单位、无量纲定义、数值精度和所有明确限定。 |
| 引用与归属 | 每个结论归属的作者或研究、参考文献所支持的具体命题、图表及公式交叉引用的目标。 |

- 小的措辞变化也可能改变命题：不要把限定范围内的结果扩展为一般规律，把有限点的拟合写成完整关系的验证，或把联合结果写成已分离各项贡献。
- 保留统计对象的区别，例如标准差、标准误、置信区间及数值误差；不能把“未发现差异”改成“相同”，或在缺少对应检验时引入统计显著性。
- 不随意调整平均、极值、差分等运算顺序或配对关系。只有相关条件明确、等价关系成立时才采用另一种表达；不将个体、单次实现和总体或集合统计互换。
- 定性研究中的参与者、引文、编码、类别、主题及分析者解释也应保持各自的归属和层级，不把描述改写为普遍性或因果判断。
- 若原句有多个科学或数学读法，标为“需作者核对”，说明差别并按需给出条件候选。不把选择解释、修复模型矛盾或补证据当作普通语言修改。
- 明显疑似错误的数值、单位、符号或科学陈述应指出并区分语言建议；未经当前任务授权及相应依据，不静默改正。明确授权的术语或精度调整按要求实施并说明。

## 术语、公式和翻译

- 在读者首次需要时清楚定义缩写、符号和术语；先定义基础对象，再定义依赖它的对象。复用既有名称，避免同一表述对应不同对象，或用近义词掩盖不同的量。
- 保留有用的数学表达，并以必要文字交代对象、变量和条件。不能为了句子好读而改变数学运算；不将近似号、量级关系或适用极限改成严格等式。
- 翻译保留原文的论断强度、逻辑、语义范围和技术细节，不沿用造成歧义的语言结构。维持项目术语表；维护双语稿时核对实质内容，不要求逐字对应或相同句长。
- 尊重作者明确要求保留的表述。后来明确的修改要求可以更新此前约定；项目专用术语和保护段落只适用于所指稿件，不传给其他作者或论文。

## 图表、附录和补充材料

- 用户要求检查或设置论文图件的风格、格式、字体、字号、配色、线宽、面板布局或导出设置时，读取 [references/figure-style.md](figure-style.md)。普通正文或图注润色无需加载。采用其中通用原则；只有明确要求沿用个人模板或指定样图时才使用个人预设。具体绘图采用当前已有工具，不依赖特定绘图技能；本文的语言润色请求不自动授权重绘。
- 图注和表注应提供独立理解所需的最小信息：对象、面板、条件、符号、尺度或归一化，以及适用的样本和不确定性定义。独立可读不意味着重复正文；目标期刊允许或需要解释性图注时，可保留必要解释。
- 核对面板顺序、对应关系、误差定义及图文一致性。不要增加图中没有呈现或文本没有依据的结论，也不为每个图固定追加总结。
- 在支持具体命题的自然位置引用附录或补充材料，避免指向不明或反复提示。跨文件引用应说明项目属于哪份文档，检查实际编号和前缀，不机械追加“Appendix”等字样。
- 主文应交代其核心论证所需的信息。推导、补充证据或实现细节的放置服从稿件与期刊要求；纯语言润色不自动授权迁移内容、重新编号或调整文件结构。
- 限制应出现在它所限定的命题附近。摘要、正文及独立图注需要分别自洽时可以重述必要条件；避免无意义重复，不机械要求全篇只出现一次。

## 输出与文件编辑

- 短段润色默认给出完整建议文本与必要解释。全面语言审核或要求逐句对照时，使用“位置｜原句｜完整建议句｜理由｜原义核对｜类别”表格；原句精确引用当前版本，不能用省略号替代影响判断的内容。
- 区分“建议修改”（明确的语言问题）、“可选微调”（原句成立的风格选择）和“需作者核对”（未解决的科学歧义）。输出语言和分类名称服从作者要求；不为了增加条目而改写正确句子。涉及歧义时不宣称已经保持原义。
- 用户只要建议时不改源文件；授权编辑时按指定范围修改。历史润色表只是候选，必须重新匹配当前原句和上下文；不得按旧行号直接批量替换。
- 修改后检查邻近段落、术语、数值、公式、引用和双语一致性。实际编辑结构化文件时检查相关语法；只有本次任务需要时进行编译或渲染，并如实报告无法完成的检查。
- 交付时说明实质调整和未解决的问题。语言改善、技术校验和期刊要求核实应分别说明，不把未执行的检查报告为已经通过。

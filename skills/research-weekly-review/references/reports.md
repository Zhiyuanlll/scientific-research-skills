# 报告、状态和渲染约定

配置中的 `runtime_dir` 是报告和共享研究状态的归属目录。时区优先配置，个人使用默认 `Asia/Shanghai`。使用当地 ISO 周命名，如 `reports/2026-W42/review/`；周一计划属于当周，引用的是上一周总结，不按相同周目录猜测配对。

每次模式目录包含 `报告.source.md`（原生 LaTeX 数学源）、`报告.md`（可视公式已嵌入）、`报告.html`（有可用 HTML 渲染依赖时）、`evidence.json`、必要的 `assets/`；review 另保存 `state_snapshot.json`。配置、共享 `current_state.json` 和运行历史位于模式目录之外。首次初始化不预填科研成果。

## 输入配置

配置记录三个相关聊天、文献推荐运行目录、已有项目发现入口、论文样式 profile、已选绘图后端及已验证的 Python 路径。报告运行按需读取近期真实材料，不自动把入口设为最高优先级。

文献推荐记录使用其现有记录工具读取 `records.json`。按运行 ID 查看实际推荐、原话反馈和论文证据，不能把摘要判断变成全文结论。周一计划不等待同一时间的新推荐。

## 证据与共享状态

`evidence.json` 至少包括本次模式、实际观察时间、报告时间范围、读取成功与失败的资料范围，以及：

- `calculations`：稳定计算 ID、所属问题、目的、版本/配置/输入、状态、指标及单位、验证结果、来源和原始日期。
- `conclusions`：论断、状态（已验证/用户报告/初步/推断/待验证/被否定）、支持/反对证据、适用条件、不确定性。
- `method_changes`：旧/新定义或假设、实现与检验状态、变更影响和需要复核的结果。
- `literature_links`：论文标识、对应问题/方法、推荐/阅读/尝试/验证状态、用户原话和来源。
- `figures`：嵌入文件、对应结论、原始数据/已有图件来源、样式来源、导出和视觉检查状态。

各来源保存实际 `uri`、可用的消息 ID/文件定位、证据日期和简短依据。缺失字段用未知或未取得，不补造日志、样本数或计算结果。详细来源在此附件保留；对用户的图注不暴露私有工作目录。

`current_state.json` 为 review 维护的完整快照：`schema_version`、`as_of`、`review_period`、`review_report`、`projects`、`domain_profiles`、`open_questions`、`key_calculations`、`conclusions`、`method_changes`、`literature_links`、`sources`、`coverage`。建议与事实分开。写入先生成本次快照、校验，再用临时文件原子替换共享状态；同目录保留上一版或归档快照。plan 不更新共享状态，以免建议被误认成新的完成证据。

文献推荐读取该共享状态后仍核对来源与新活动，并保存自己的状态事件；它不回写此共享文件。缺少周总结时，其他任务可以基于最近可核实资料继续，并标明缺口。

## 数学与图像

原生源报告使用正文 `$...$` 和独立块 `$$...$$`。复杂多行公式可在数学块中使用 `aligned`；来源的符号和必要条件一同保留。不从未知符号或图像猜公式。

渲染命令（替换绝对路径）：

```text
python3 <skill_dir>/scripts/render_report.py --source <报告.source.md> --output <报告.md> --html <报告.html> --font "Times New Roman" --node <已验证node路径> --marked-module <marked的ESM模块路径>
```

脚本使用本地 XeLaTeX 排版数学，输出公式 PDF 与 PNG，并在 `.md` 中用实际图片替换数学源；`.source.md` 不覆盖。HTML 由本地 `marked` 生成并将本地图像嵌入，不能依赖远程公式服务。脚本不下载依赖，不执行科研计算，不改写公式含义。公式中的自定义宏需先依据原稿展开或给出已有定义，不能为编译成功删去项或改变表达。

公式排版错误、缺字体或缺工具需明确报告，保留源和可交付正文；不能把未渲染源当作最终可视公式。生成 HTML 不代表已经做视觉检查；实际检查页面和公式/图像输出后才能报告视觉验收通过。

## 图的样式优先级

先读指定 `nature-figure` 的真实路由与项目样式说明，再读取配置 profile。以当前明确要求、选定论文样图和实际插入尺寸为优先；profile 是可核查的样式入口，不把一张图的源尺寸强加给所有图。图型不匹配时只继承字体、颜色等视觉规则，重新安排数据与面板。

原图可直接支持结论时优先复用已核实导出，不运行有副作用的生产绘图脚本。需要重绘时复制脚本到本次报告目录，使用原始数据，保留排除和处理规则，并按最终尺寸检查。没有新关键结果时可以不新增图。

# 在项目中固定使用独立计算队列

技能允许按 description 自动选择，也可通过 `$computation-queue-runner` 显式调用。自动匹配不等于每次都能无条件选中；需要项目内一致执行时，可将以下规则合并到该项目自己的 `AGENTS.md`。此文件是可复制的建议，不自动修改用户的其他项目或个人全局配置。[官方技能说明](https://learn.chatgpt.com/docs/build-skills)、[官方 AGENTS.md 说明](https://learn.chatgpt.com/docs/agent-configuration/agents-md)

```markdown
## 正式计算提交

- 所有正式科研计算，不论时长、单算例或批量，都读取并遵循 computation-queue-runner 技能，通过独立系统服务或已有批调度器运行。
- 用户说“开始计算”或“提交这批计算”即授权 Codex 在该任务范围内检查脚本、核对资源并执行提交；提交后核验调度器状态。不要只交付命令让用户手动执行，也不要把相同提交授权重复询问一遍。
- Codex 负责准备、检查、提交、查询与诊断；独立队列负责运行、串联后续任务、保存状态和结果，不依赖聊天活跃或定时唤醒。
- 仅生成计划/脚本的请求不启动生产计算；语法检查、单元测试和开发诊断可直接执行。正式科学算例即使很短，也不以“快速检查”名义绕过队列。
- 遵守项目实际并发、线程、内存、加速器和科学验收约定。计划、排队、运行、进程结束和科学验收通过分别记录。
```

安装后还应确认技能在当前环境能被发现；技能目录路径可按本机实际安装方式填写。项目有现成 Slurm、PBS 等调度器时复用现有设施，不强制换成工作站 systemd。若需要修改注销/电源策略或新增访问权限，应说明实际需要并遵循已有授权边界。

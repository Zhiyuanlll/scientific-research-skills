# 阶段与验证约定

## 选择边界

阶段边界应对应可保存、可检查、可复用的数据产品。可独立重绘的图件通常无需重跑求解；不同求解器消费同一物理输入时共用输入约定。少量串行步骤不必拆成独立服务。

先从已有入口、配置、真实读写关系追踪流程，不能由目录名推断所有权。若多个分支输出同名文件，先分清版本和活动配置，再决定是否合并。代码表示实现，运行配置表示实际启用的选项，完成且验收的记录表示实际计算；论文或设计说明不能代替这三类证据。

按任务选用模板中的字段；科学上无关的字段写明不适用，不填虚假值。

| 约定 | 需要回答的问题 |
|---|---|
| 输入 | 来自哪个原始数据/上游运行？哪个版本？是否允许缺失？ |
| 物理含义 | 是测量、拟合、数值近似、模型预测还是图形派生量？ |
| 结构 | 形状、字段、dtype、坐标、索引、周期边界、缺失值如何表示？ |
| 单位和定义 | 单位、归一化、参考态、符号、面积/体积/长度因子是什么？ |
| 参数 | 哪些改变物理、哪些控制数值误差、哪些只分配资源？ |
| 随机性 | seed 如何派生？哪些对照共享 realization？重复单位是什么？ |
| 输出 | 哪些是必需数值产物，哪些是诊断/可重绘产品？ |
| 验收 | 使用什么参考、指标、阈值和覆盖范围，失败如何影响下游？ |
| 完成与恢复 | 谁写完成标记？检查点包含哪些状态？何种变化会失效？ |

## 参数分层与运行身份

物理参数包括材料、边界条件、场定义和模型闭合。数值参数包括网格、容差、步长、插值和扫描协议。调度参数包括任务并发、线程和队列。线程变化可能改变浮点规约，不能据“仅调度变化”直接保证数值等价。

保留完整配置快照；复用指纹覆盖该阶段实际消费的配置投影、上游内容校验值、代码/算法版本、随机流规则及输出 schema。不要让无关图题改动使所有物理计算失效，也不要因算法版本被遗漏而复用过期检查点。

`case_id` 标识物理/数值条件，`run_id` 标识一次可追溯执行或尝试。稳定的 case 身份支持重试，但不授权覆盖历史。相同 seed 不代表相同随机场：网格、随机生成器、流派生、分布和调用顺序都可能影响 realization。

## 验证矩阵的用法

针对最危险的失败模式选择检查，并先规定失败后采取的动作。

| 风险 | 检查示例 | 失败后的动作 |
|---|---|---|
| 单位、坐标或索引错配 | 可解析人工输入、往返映射、量纲核查 | 阻止该接口下游计算 |
| 能量与力实现不一致 | 远离非光滑点的有限差分导数对照 | 修正实现并重算受影响阶段 |
| 约束或守恒被破坏 | 记录每次/关键步最大残差及允许误差 | 保留诊断，拒绝正式完成 |
| 数值偏差影响结论 | 网格、容差、域尺寸或步长敏感性 | 限定可靠范围或调整数值策略 |
| 参考数据泄漏 | 按样本来源划分拟合与独立验证 | 重建验证分组，不宣称独立验证 |
| 随机波动被误当趋势 | 多个独立样本、配对设计、误差传播 | 增补证据或降低结论强度 |
| 未收敛输出被聚合 | 验收状态、排除原因、预期/有效数量 | 阻止完整汇总或输出明确 partial |

不普遍强制有限差分、网格加密或特定置信水平：选择取决于算法与目标。参考容差、指标和样本量需要依据；没有依据时可完成测试程序，但验收仍为待确定。

对非光滑算法、随机求解器和近似模型，应分别说明什么不变量仍适用，以及数值/统计比较的含义。拟合优良不等于机制唯一，代理输出不等于独立实验或原子基准。

## 最小闭环的完成条件

选择覆盖真实接口和主要风险的代表性小算例，记录输入、执行命令、资源和壁钟时间，产出可复查的数值比较与图件。小试只支持它覆盖的范围，不证明大尺寸、全材料或全部参数已验证。

从小试扩展时计算真实任务矩阵和资源估计，记录估计来源。对尚未跑过的尺寸明确外推不确定性，并预先设置异常耗时、持续不收敛或资源超限时的停止条件。

# HEA 案例：从科学问题搭建可追溯的计算工作流

## 案例边界与来源

本案例说明一种可复用的搭建逻辑，来源是现存 HEA Peierls–Nabarro（PN）项目文档。
它不是逐日开发年表，也不证明文档所述任务均已完成或通过科学验证。
下文的“文档事实”表示来源记载的架构、约定或审计规则；“推荐迁移”表示对新项目的建议。
本文件未独立运行 HEA 求解器、核验全部结果或检查每项代码实现。
源文档包含历史设定和后续修订；本案例不是生产配置，也不提供可直接照抄的参数组合。
源文件不随此技能包分发，以下路径为脱敏逻辑路径，供原项目维护者定位：

- `paper-workflow/SKILL.md`：科学主线、模块边界、图件溯源及同步规则。
- `paper-workflow/references/workflow-contract.md`：输出契约、完成条件、恢复及重算边界。
- `HEA_PN_workflow6.0/docs/THREE_MODULE_WORKFLOW.md`：三模块架构与历史运行说明。
- `HEA_PN_workflow7.0/CHANGELOG.md`：双项 GSFE 及可分发环境的版本变化。
- `HEA_PN_workflow8.0/docs/WORKFLOW8_PARALLEL_ACCELERATION.md`：并行分支与数值对照要求。

## 1. 从科学问题确定证据链

**文档事实。** 项目围绕“合金失配如何通过滑移面随机场影响位错势垒和临界分切应力（CRSS）”组织。
其关键检验是：溶质牵引场与层错恢复牵引场能否复现原子尺度位错响应，并解释机制差异。
文档把论证连接成以下链条：

```text
合金失配与材料参数 → 原子场统计 → PN 能量景观
→ 原子/PN 定量比较 → 化学/畸变对照 → 有限尺寸 CRSS 与参数预测
```

**推荐迁移。** 新项目先写清目标物理量、需要支持的结论、可独立比较的证据与未验证范围。
将“实现了算法”“算例收敛”“与基准一致”“可外推预测”设为不同状态。
先画出证据依赖图，再决定脚本、目录与计算资源，避免由现有程序目录倒推科学论证。

## 2. 按证据角色划分三个模块

**文档事实。** 三个模块通过生成的数据衔接，随机 PN 采样不进入原子统计阶段。

| 模块 | 科学职责 | 主要阶段或产物 | 解释边界 |
|---|---|---|---|
| `statistic_data` | 建立物理输入 | 原子计算 → PN 场提取 → 层分析 → 多种子聚合 | 层统计解释层间物理；PN-method 统计提供模型定量输入 |
| `verify_data` | 检验模型与机制 | 原子/PN 景观、NEB、分解、形貌、CRSS 及比较摘要 | 对照证据与误差需支持所报告的适用范围 |
| `freedom_data` | 扩展已建立的模型 | 原子参数采样、理想相关长度扫描、手动参数扫描 | 合成场是预测输入，不作为原子验证数据 |

`freedom_data` 的物理输入依赖已完成的材料专属统计，材料常数的默认值不能替代缺失场统计。
**推荐迁移。** 保留“输入建立—独立验证—范围扩展”的职责分离；模块数量可随研究问题调整。
每个模块约定唯一负责的输出，下游只消费带版本与完成状态的输入。

## 3. 把物理定义写入接口契约

**文档事实。** HEA 项目不仅约定文件名，还约定字段的物理构造、符号与映射方式。
例如，其 PN 溶质牵引采用 `tau_sol = 0.5 * (Top1 + Top2 + Bot1 + Bot2)`。
底层牵引符号已在提取时修正，各层独立映射至周期 PN 网格；该系数不能替换为四层算术平均。
层错场采用未弛豫原子编号定义的完整原子列，列能量变化除以投影列面积。
两类源表的采样形状可以不同；进入比较与求解前需分别映射到统一目标网格。

**推荐迁移。** 每个跨模块字段至少记录以下内容：

- 名称、数学定义、单位、符号、坐标、周期性及独立样本的含义。
- 源数据、提取脚本、版本、参数、随机种子和目标网格。
- 可接受值域、缺失策略、映射方式与兼容字段的用途。
- 输出模式版本、完成条件、上游指纹及下游消费者。

不要把这些 HEA 场公式或周期偶极约束当作其他材料体系的默认物理模型。

## 4. 先建立小算例的定量验证

**文档事实。** `verify_data` 将原子 NEB 与 PN 能量景观、路径、形貌和 CRSS 连接比较。
在严格双倍域偶极模式下，镜像半域满足 `phi_R(x + Lx/2,y) = b - phi_L(x,y)`，不是独立自由度。
相应状态与力投影需要贯穿弛豫、PN-NEB 和应力扫描，并记录对称性与线间距误差。
文档要求先检查完成摘要，再以比较摘要和指标摘要索引结果。

**推荐迁移。** 在大规模扫描前选择有明确基准的小算例，冻结输入、边界条件和验证指标。
适合检查的层次包括能量与力一致性、解析极限、网格/容差敏感性、独立方法比较与统计不确定性。
先声明误差判据及其物理依据；未通过时记录影响范围，不以程序退出成功代替验证。
只对已经检验过的材料、尺寸、模型和加载条件作相应强度的结论。

## 5. 用匹配对照解释机制

**文档事实。** `verify_decomposition` 的 full 情形复用主 PN 计算，不能作为额外独立样本计数。
文档要求展示 full、chemical、distortive 及可加性残差，不能预设贡献严格相加。
双项 GSFE 语境下，chemical 对照去除溶质牵引涨落，distortive 对照使 `a1/a2` 均匀化。
此处名称对应指定场隔离操作；它们与原子位置冻结后替换化学组分的对照循环并非同一实验。

**推荐迁移。** 对每个对照写明“保留什么、改变什么、比较哪个量”。
尽量匹配随机实现、几何、加载、求解与容差，防止样本变化混入机制差异。
报告配对差异及非可加部分，并避免把共享数据或复用计算当成独立重复。

## 6. 使中断恢复与并行聚合遵守科学完成条件

**文档事实。** 绘图失败时，已完成的 CRSS 摘要可用于恢复，不必重跑数值计算。
后续约束扫描使用逐点追加检查点，记录尝试历史；恢复前核验扫描指纹，仅复用兼容且收敛的点。
并行 worker 只写自己的任务目录和任务摘要，共享统计由所有任务完成后的独立聚合步骤生成。
任务级摘要与科学阶段摘要承担不同职责；任一必需任务缺失时，正式聚合不得假定全体完成。
部分诊断产物需要显式 `partial` 标记，不能覆盖完整科学结果。

**推荐迁移。** 最小恢复单元应具有稳定标识、输入指纹、状态、返回码、收敛指标及原子化提交规则。
为每个 worker 分配独立写入目录，集中聚合并检查预期任务集合，控制线程嵌套与资源超配。
按任务耗时、内存与 I/O 实测选择进程/线程，任务结束及时释放资源；不复制原机器的资源数。
将数值失败、未运行、有效删失、部分结果和科学完成分别建模。
例如 HEA 的收敛但达到应力上限而未越过完整周期的状态可为右删失；求解失败仍是未完成。

## 7. 分开物理升级、执行优化与结果失效范围

**文档事实。** 7.0 增加受约束的双项 GSFE 拟合、`local_two_term` 求解与同步移动窗口。
其机制分解同步改变 `a1/a2`，保留的旧 `omega` 列不等于双项场的主要科学表征。
7.0 还采用可移植环境说明和源码分发，避免连带分发历史输出、日志与缓存。
8.0 被记为实验性能分支，改变行并行、相位更新、投影及可选数值后端。
文档要求在相同小算例、种子、容差与应力路径下对照参考实现，才能与参考结果共同使用。

**推荐迁移。** 每次变更给出受影响字段、阶段、派生量、图件和需要重算的范围。
HEA 契约中的例子：提取符号改变使相应场及下游失效；弹性核改变使 PN 结果失效。
能量归一化或 CRSS 换算改变需重建派生指标；纯绘图修改通常只需从原数值表重绘。
保留旧结果的配置、版本与指纹，分目录存储；不要用“最新文件”隐式拼接不同模型。
源文档出现历史尺寸序列、相关长度约定与后续修订，实际运行须核对当前源码、配置和完成摘要。

## 8. 让论文结论追溯到已完成证据

**文档事实。** 项目设有图件来源矩阵，区分直接数据、验证比较、合成预测及未来占位项。
稿件引用了图片文件不证明图片存在；计划图件也不证明支撑计算已经完成。
实现由源码确认，实际运行由完成摘要、输入与表格确认，稿件解释需与这些证据保持一致。
重大变更要求同步输出契约、说明和图文；该规则不代表存在脱离活动任务的自动同步机制。

**推荐迁移。** 为每项主结论保存“结论 → 图/表 → 源表 → 完成摘要 → 精确配置与版本”的链条。
图注独立说明物理量、样本与不确定性；正文保留模型假设、例外、删失与尚未验证的范围。
若文稿、说明、源码和结果冲突，列出差异并解决，不能仅依赖较新的文件名判定科学有效性。
交付前分别检查可运行性、数值有效性、科学证据与可迁移性，再写摘要和结论。

# 打包与验证记录

本包包含 23 个完整技能目录。精确来源散列、分享版适配、生成时间和文件清单见 PACKAGE_MANIFEST.json。此技术记录用于追溯文件和检查，不规定技能的使用顺序。

## 文件与适配

工具集以 22 项分享快照为基础，整合 computation-queue-runner 的独立计算执行能力，并在工作流、安装、依赖与周期协同说明中衔接完整流程。原有研究与写作技能的科学处理逻辑保持，scientific-workflow-builder 增加可选的独立执行交接说明。公开发布版保留来源与许可文件、入口再分发标记、GitHub 获取方式及散列记录；不改动使用者已安装技能或真实运行任务。

分享快照保留原有六个文件的兼容处理：四项 author/version 元数据移入 metadata，阅读评测的作者本机路径改为通用示例，提案与文献 pipeline 加入真实可用工具和平台适配说明。具体路径和调整理由见 share_copy_modifications。

本包不含个人 vault、周报、current_state.json、真实聊天 ID、任务配置、账号密钥、字体、生产图件或 HEA 求解器。模板只提供配置起点，不代表资料、外部服务或任务已接入。
